Exemples de code

Quatre usages courants, dans trois langages. Remplacez PREFIX.SECRET par votre clé, lue depuis une variable d'environnement.

Lister les lignes

GET
curl {{ api_base_url }}/api/v1/voyage/routes/ \
  -H "X-API-Key: $TOUPAC_API_KEY"

Filtrer les voyages disponibles

GET + filtres
curl -G {{ api_base_url }}/api/v1/voyage/trips/ \
  -H "X-API-Key: $TOUPAC_API_KEY" \
  --data-urlencode "status=scheduled" \
  --data-urlencode "departure_date=2026-09-15"

Créer une réservation

POST
curl -X POST {{ api_base_url }}/api/v1/voyage/reservations/ \
  -H "X-API-Key: $TOUPAC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "trip": "0b7f1e2a-3c4d-4e5f-8a9b-0c1d2e3f4a5b",
    "passenger": "7c2d9f01-1a2b-4c3d-9e8f-5a6b7c8d9e0f",
    "seat_label": "A1",
    "amount_xof": 25000,
    "payment_method": "wave"
  }'

Client réutilisable

Session requests
import os
import requests

BASE = "{{ api_base_url }}/api/v1"

session = requests.Session()
session.headers["X-API-Key"] = os.environ["TOUPAC_API_KEY"]

response = session.get(f"{BASE}/voyage/routes/", timeout=10)
response.raise_for_status()
for route in response.json()["results"]:
    print(route["code"], "—", route["name"])

Créer une réservation, en gérant les erreurs

POST + validation
response = session.post(
    f"{BASE}/voyage/reservations/",
    json={
        "trip": trip_id,
        "passenger": passenger_id,
        "seat_label": "A1",
        "amount_xof": 25000,
        "payment_method": "wave",
    },
    timeout=10,
)

if response.status_code == 201:
    print("Réservation", response.json()["id"])
elif response.status_code == 400:
    # Erreur de validation : un dict {champ: [messages]}
    for field, messages in response.json().items():
        print(f"{field}: {'; '.join(messages)}")
else:
    response.raise_for_status()

Parcourir toutes les pages

Suivre `next`
def iter_all(path, **params):
    """Génère chaque élément, page après page."""
    url = f"{BASE}{path}"
    while url:
        payload = session.get(url, params=params, timeout=10).json()
        yield from payload["results"]
        url, params = payload["next"], None  # `next` porte déjà les paramètres

for parcel in iter_all("/colis/parcels/", status="in_transit"):
    print(parcel["tracking_number"])

Appel de base

fetch
const BASE = "{{ api_base_url }}/api/v1";
const headers = { "X-API-Key": process.env.TOUPAC_API_KEY };

const response = await fetch(`${BASE}/voyage/routes/`, { headers });
if (!response.ok) throw new Error(`HTTP ${response.status}`);

const { results } = await response.json();
results.forEach((route) => console.log(route.code, "—", route.name));

Filtrer les voyages disponibles

URLSearchParams
const query = new URLSearchParams({
  status: "scheduled",
  departure_date: "2026-09-15",
});

const trips = await fetch(`${BASE}/voyage/trips/?${query}`, { headers })
  .then((r) => r.json());

console.log(`${trips.count} voyage(s) programmé(s)`);

Créer une réservation

POST
const response = await fetch(`${BASE}/voyage/reservations/`, {
  method: "POST",
  headers: { ...headers, "Content-Type": "application/json" },
  body: JSON.stringify({
    trip: tripId,
    passenger: passengerId,
    seat_label: "A1",
    amount_xof: 25000,
    payment_method: "wave",
  }),
});

const body = await response.json();
if (response.status === 201) {
  console.log("Réservation", body.id);
} else if (response.status === 400) {
  Object.entries(body).forEach(([field, messages]) =>
    console.error(`${field}: ${messages}`),
  );
}

Respecter le quota

Retry-After
async function callWithRetry(url, options, attempts = 3) {
  for (let i = 0; i < attempts; i++) {
    const response = await fetch(url, options);
    if (response.status !== 429) return response;

    const wait = Number(response.headers.get("Retry-After") ?? 60);
    await new Promise((resolve) => setTimeout(resolve, wait * 1000));
  }
  throw new Error("Quota dépassé, abandon après plusieurs tentatives");
}
