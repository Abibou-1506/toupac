L'API TOUPAC

TOUPAC est un système de gestion du transport pour l'Afrique de l'Ouest. Son API REST vous permet de réserver un siège sur un voyage, suivre un colis de bout en bout, consulter une flotte et ses positions GPS, ou récupérer des factures — les mêmes opérations que celles de nos applications, exposées à vos systèmes.

Multi-tenant

Chaque clé API est rattachée à une compagnie de transport. Vos requêtes ne voient jamais que les données de cette compagnie — l'isolation est appliquée côté serveur, vous n'avez aucun filtre à poser.

REST & JSON

Verbes HTTP standards, corps et réponses en JSON UTF-8, codes de statut usuels. Les montants sont en francs CFA (XOF), entiers : le XOF n'a pas de sous-unité.

HTTPS obligatoire

En production, seul le HTTPS est accepté. Une requête en clair est refusée — votre clé transiterait en clair sur le réseau.
