Quick start

Trois étapes, une minute.

  1. Demandez une clé API

    Votre contact TOUPAC crée la clé pour votre compagnie et choisit ses scopes. Vous recevez une valeur de la forme prefix.secret — elle n'est affichée qu'une fois.

  2. Envoyez votre première requête

    Lister les lignes régulières de la compagnie :

    curl
    curl {{ api_base_url }}/api/v1/voyage/routes/ \
  -H "X-API-Key: PREFIX.SECRET"

  3. Lisez la réponse

    200 OK
    {
  "count": 3,
  "next": null,
  "previous": null,
  "results": [
    {
      "id": "0b7f1e2a-3c4d-4e5f-8a9b-0c1d2e3f4a5b",
      "name": "Dakar → Bamako",
      "code": "DKR-BKO",
      "distance_km": "1450.00",
      "duration_minutes": 1440,
      "is_active": true
    }
  ]
}

Pas encore de clé ? Écrivez à {{ support_email }} en précisant la compagnie et les opérations visées : nous vous ouvrons un environnement de test.
