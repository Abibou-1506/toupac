Pagination

Toutes les listes sont paginées. La réponse porte quatre clés : le total, les URLs de page suivante et précédente (null aux extrémités), et les éléments.

Réponse paginée
{
  "count": 128,
  "next": "{{ api_base_url }}/api/v1/voyage/trips/?page=3",
  "previous": "{{ api_base_url }}/api/v1/voyage/trips/?page=1",
  "results": [ ... ]
}
ParamètreDéfautMaximumDescription
page1—Numéro de page, à partir de 1.
page_size25100Éléments par page. Au-delà de 100, la valeur est ramenée à 100.

Pour parcourir un jeu complet, suivez next jusqu'à null plutôt que d'incrémenter page vous-même : vous éviterez de sauter des éléments si le jeu évolue pendant le parcours.

Deuxième page, 50 par page
curl "{{ api_base_url }}/api/v1/voyage/trips/?page=2&page_size=50" \
  -H "X-API-Key: PREFIX.SECRET"
